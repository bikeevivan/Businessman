# Бизнесмен (Businessman)

Экономическая песочница / тайкуклон: покупайте предприятия, торгуйте сырьём и товаром на бирже, вкладывайте в недвижимость и автомобили, конкурируйте с ИИ-оппонентами и достигните целевой суммы.

## Запуск из редактора

1. Откройте проект в Godot 4.7.2.
2. Нажмите F5 или кнопку «Play».
3. Главное меню → «Новая игра», выберите количество противников и целевую сумму.

## Сборка Windows-инсталлятора

```powershell
powershell -ExecutionPolicy Bypass -File "E:\Games\TestGame\installer\build.ps1"
```

Чтобы не увеличивать версию в `version.txt`, добавьте флаг `-NoBump`:

```powershell
powershell -ExecutionPolicy Bypass -File "E:\Games\TestGame\installer\build.ps1" -NoBump
```

Результат: `dist/Businessman-Setup-MAJOR.MINOR.exe`.

## Сборка веб-версии

```powershell
powershell -ExecutionPolicy Bypass -File "E:\Games\TestGame\tools\build_web.ps1"
```

Результат: `build/web/index.html` и архив `build/web/Businessman-web.zip`.

## Публикация на itch.io (запуск в браузере)

Полная инструкция по публикации HTML5-игр также доступна в официальной документации itch.io: https://itch.io/docs/creators/html5.

### 1. Создание проекта на itch.io

1. Войдите в свой аккаунт на https://itch.io и нажмите **«New Game»** (или редактируйте существующий проект).
2. В поле **«Kind Of Game»** обязательно выберите **HTML Game**. Если выбрать другой тип, itch.io не предложит опцию «This file will be played in the browser», и игра не запустится в браузере.
3. Заполните название, описание и остальные поля по желанию.

### 2. Сборка веб-версии

Выполните в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File "E:\Games\TestGame\tools\build_web.ps1"
```

После сборки вы получите:

- `build/web/index.html` — точка входа;
- `build/web/Businessman-web.zip` — архив для загрузки на itch.io.

### 3. Загрузка архива и настройка запуска в браузере

1. На странице проекта перейдите в раздел **«Upload files»**.
2. Загрузите файл `build/web/Businessman-web.zip`.
3. После загрузки откройте настройки этого файла и включите галочку **«This file will be played in the browser»**.
4. В блоке **«Embed options»** рекомендуется:
   - Выбрать режим **«Embed in page»** и указать размер вьюпорта **1280×720** (фиксированное разрешение игры).
   - Либо выбрать **«Click to launch in fullscreen»** — тогда игра откроется во весь экран по клику.
   - Включить **«Fullscreen button»**.
   - Оставить включённым **«Click to Play»** (из-за политик автовоспроизведения браузеров музыка всё равно начнёт играть только после первого клика игрока).

> В пресете `Web` задан `html/canvas_resize_policy=1` (Project Resolution), а в `project.godot` установлены `window/stretch/mode="canvas_items"` и `window/stretch/aspect="keep"`. Игровой канвас всегда 1280×720 и масштабируется браузером с сохранением пропорций; чёрные поля появляются только при несовпадении соотношения сторон.
>
> Сборка собрана с `thread_support=false`, поэтому заголовки SharedArrayBuffer / COOP-COEP **не требуются**.

### 4. Цена и донаты

У HTML-игр на itch.io платежи работают только как донаты (pay-what-you-want). Чтобы игроки могли поддержать разработчика прямо на странице игры:

1. В разделе **«Pricing»** выберите **«$0 or donate»** (или аналогичный вариант «pay what you want»).
2. itch.io сам покажет на странице игры кнопку **«Support This Game»** / «Download or donate» — сторонние платёжные сайты не используются.

### 5. Лимиты itch.io

Перед публикацией убедитесь, что архив укладывается в ограничения itch.io для HTML5-игр:

- не более **1000 файлов** в архиве;
- суммарный размер распакованного содержимого ≤ **500 МБ**;
- один файл ≤ **200 МБ**;
- itch.io сам дополнительно сжимает (gzip) файлы `html`, `js`, `wasm` и `pck`, поэтому отдельно сжимать их перед загрузкой не нужно.

Наша сборка укладывается в эти лимиты: обычно **9 файлов** и примерно **62 МБ** распакованных данных (`index.wasm` ≈ 37.7 МБ + `index.pck` ≈ 25.5 МБ + служебные файлы).

### 6. После публикации

1. Скопируйте адрес опубликованной страницы игры (формат `https://<user>.itch.io/<game>`; для этого проекта — `https://bikeevivan.itch.io/businessman`).
2. Откройте файл `scripts/autoload/game_state.gd` и вставьте этот адрес в константу:

   ```gdscript
   const ITCH_PROJECT_URL: String = "https://bikeevivan.itch.io/businessman"
   ```

3. Пересоберите веб-версию (`tools/build_web.ps1`) и Windows-инсталлятор (`installer/build.ps1`), если он тоже должен вести на itch.io.
4. Загрузите обновлённую сборку на itch.io.
5. В главном меню игры кнопка **«Поддержать разработчика»** открывает страницу проекта на itch.io. На самой странице itch.io отображается кнопка **«Support This Game»** для доната (платежи обрабатывает itch.io, сторонние сайты не используются).

Если `ITCH_PROJECT_URL` оставить пустой, кнопка «Поддержать» покажет игроку сообщение: «Ссылка на поддержку пока не настроена» / «Support link is not configured yet».

## Примечания по сборке

- Каталоги `build/` и `dist/` содержат артефакты сборки и помечены пустыми файлами `.gdignore`, чтобы Godot не сканировал их при импорте проекта.

## Управление

- ЛКМ — выбор кнопок, лотов на бирже, покупка/продажа предприятий.
- ESC — вызов меню паузы с сохранением.
