# Сгенерированные ассеты

Здесь лежит всё, что сделал локальный арт-агент `artist` через ComfyUI (`tools/comfy/`).
Ассеты генерируются локально и бесплатно; в репозиторий попадают уже готовые файлы.

- `img/` — референсные картинки (текст → картинка, FLUX.3 Klein int8).
- `models/<slug>/` — 3D-модели, по подпапке на ассет (картинка → 3D, Pixal3D / TRELLIS.2).
  Демо-модель лежит прямо в `models/` — это legacy-исключение, новые ассеты кладём в подпапки.

## Демо-примеры

Первый сквозной прогон пайплайна, остаётся в репозитории как образец:

| Файл | Размер | Что это |
| --- | --- | --- |
| `img/9d1d2b5f_000.png` | 0.95 МБ | референс персонажа, FLUX.3 Klein, seed 777 |
| `models/businessman_char.glb` | 1.33 МБ | TRELLIS.2, 11996 трис / 9554 верт., текстуры 512×512 (`288.value` = 512) |

`img/.gitkeep` держит папку в git; в `models/` он не нужен — там лежит демо-модель (а новые подпапки
`models/<slug>/` непустые сами по себе).

## Имена файлов

Это конвенция, а не гарантия. Префиксы задаются в workflow (`134.filename_prefix` = `<slug>_<seed>`,
`322.filename_prefix` = `<slug>`), но ComfyUI добавляет к ним счётчик, а `fetch_outputs` сохраняет файл как
`<первые 8 символов prompt_id>_<номер>.<ext>` (например `7607d3b2_000.png`). То есть имя после выгрузки такое,
каким его вернул инструмент; переименование в `<slug>.glb` / `<slug>_<seed>.png` делает оркестратор или
пользователь (у агента `artist` нет shell) и указывает соответствие в отчёте.

`<slug>` — латиница в нижнем регистре через `_`, коротко и по смыслу: `hero_businessman`,
`car_boxy`, `factory_small`. Для моделей путь к исходной картинке и параметры (движок, `288.value`,
`target_face_count`, seed) держи в `<slug>.md` рядом с GLB, если нужно воспроизвести результат.

## Правила

- `fetch_outputs` фильтра не имеет и тянет **все** выходы прогона: у 3D это temp-превью PNG и промежуточные
  `preview3d_advanced_*.glb`. Настоящий результат — файл ноды `322` (`Save3DAdvanced`, `type=output`) из
  `outputs_by_node["322"]`. Поэтому 3D выгружается в `models/<slug>/`, а лишнее удаляет и переименовывает
  результат в `<slug>.glb` оркестратор/пользователь.
- Размер модели задают текстуры: `288.value` = 512, `224.resolution` = 512, `233.resolution` = 512
  (крупный «геройский» объект — до 1024). Ориентир — **0.5–2 МБ на модель**.
- `target_face_count` = 10000–40000: на вес файла влияет слабо, но на производительность Godot — напрямую.
- Картинка-референс — один объект на чистом однотонном фоне, без текста.
- Содержимое сгенерированных файлов руками не правится (переименовать — можно); при необходимости они
  пересоздаются запуском `artist`.
- Сами workflow (исходники) лежат в `tools/comfy/workflows/` и не изменяются.
